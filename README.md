# Chess Helper

Минималистичное расширение для Firefox: читает позицию на доске Chess.com, анализирует её локально через Stockfish 19 Lite и показывает лучший найденный ход.

```text
Ⅱ   e2–e4   +0.20   ⋯
```

## Что умеет

- Показывает ход и оценку позиции для обеих сторон.
- Отмечает начальную и конечную клетки на доске.
- Обновляет подсказку после хода.
- Позволяет выбрать время анализа: 0,6, 1,2 или 3 секунды.
- Принимает FEN для подключения посреди партии.
- По переключателю выполняет ходы Stockfish за выбранную сторону.
- Работает без сервера анализа: движок и WASM входят в репозиторий, позиции никуда не отправляются.

Автоход по умолчанию выключен. Оценка указана с точки зрения белых; положительное число означает преимущество белых. Очередь хода и глубина анализа доступны при наведении на ход и оценку.

## Установка в Firefox

1. Нажмите **Code → Download ZIP** на странице этого репозитория.
2. Распакуйте скачанный архив.
3. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
4. Нажмите **«Загрузить временное дополнение» / Load Temporary Add-on**.
5. Выберите **`manifest.json` в корне распакованного проекта**.
6. Обновите страницу Chess.com, если она уже была открыта.

Не выбирайте `sources/stockfish-19.0.1-source.zip`: это исходники движка, а не расширение. Если Firefox пишет `does not contain a valid manifest`, проверьте, что выбран именно `manifest.json` этого проекта.

Это временная установка: после перезапуска Firefox дополнение нужно загрузить снова. Для постоянной установки в обычный Firefox необходима подпись Mozilla. Сборка перед установкой не требуется.

## Использование

1. Откройте новую партию, например [против компьютерного бота](https://www.chess.com/play/computer).
2. Нажмите **▶ до первого хода**, чтобы начать отслеживание.
3. Следуйте подсказке: жёлтая рамка отмечает исходную клетку, зелёная — конечную.
4. **Ⅱ** выключает анализ; **⋯** открывает настройки.

Если партия уже началась или появилось **«Нужен FEN»**, откройте **⋯**, вставьте полный FEN текущей позиции и нажмите **↵** или Enter. Фигуры должны совпадать с доской. FEN должен правильно задавать очередь хода, права рокировки и взятие на проходе.

Кнопка **⧉** копирует последнюю отслеженную позицию. Она не восстанавливает неизвестную позицию с сайта.

### Автоход

1. Включите анализ кнопкой **▶**.
2. Откройте **⋯**. В поле **«Сторона»** оставьте **«Авто»** или выберите цвет вручную.
3. Включите переключатель **«Автоход»**.

В режиме **«Авто»** расширение запоминает цвет, который находится внизу доски при включении автохода. Настройки сразу показывают выбранный цвет. Если доска уже перевёрнута относительно вашей стороны или её ориентацию не удалось распознать, выберите цвет вручную. Переворот доски после включения не меняет выбранный цвет.

При сворачивании Firefox или переходе на другую вкладку расширение продолжает автоход в фоне. Firefox может замедлять работу фоновой вкладки, поэтому ходы иногда выполняются позже выбранного темпа.

В поле **«Темп»** можно выбрать случайную паузу после завершения анализа:

| Темп | Пауза перед ходом |
| --- | --- |
| Без паузы | 0 с |
| Быстрый | 0,3–0,9 с |
| Обычный (по умолчанию) | 0,8–2,4 с |
| Спокойный | 1,5–4,5 с |

Пауза не меняет выбранный движком ход, силу или время анализа. Подсказка появляется сразу после расчёта, автоход выполняется позже. Перед кликом позиция и очередь хода проверяются снова; выключение автохода, изменение настроек или позиции отменяет отложенный ход. Пауза расходует время на часах: автоматического сокращения при цейтноте нет. Этот режим не гарантирует нераспознаваемость расширения или отсутствие блокировки.

Расширение ходит только за выбранный цвет и ждёт ответа соперника. Для превращения пешки оно выбирает фигуру, указанную движком, если сайт показывает меню превращения.

Отключение анализа, смена стороны, новая партия, ввод FEN или потеря синхронизации выключают автоход. После этого его нужно включить вручную. Перед выполнением хода расширение повторно сверяет фигуры с проанализированной позицией; один и тот же ход повторно не отправляется.

Если ход не принят за три секунды, появится **«Ход не принят»** и автоход отключится. Если доску закрывает окно или панель — **«Доска перекрыта»**. Уберите препятствие, проверьте позицию и включите автоход снова. Сайт может не принимать программные события мыши; обход проверки доверенных событий не предусмотрен.

## Ограничения

Поддерживаются обычные шахматы и доски с DOM-классами `piece` и `square-XY`. Chess960 и другие варианты не поддерживаются. Изменения разметки Chess.com могут потребовать обновления расширения.

Если пропущено больше двух полуходов или позицию нельзя однозначно восстановить, подсказка исчезает до синхронизации по FEN или начала новой партии. Stockfish Lite слабее полной сборки; результат партии не гарантируется.

Проверено в настоящем Firefox на локальной тестовой доске: загрузка WASM, анализ, обновление после двух полуходов, переворот доски, сброс устаревшей подсказки, ввод FEN, автоход за оба цвета, отмена анализа и превращение пешки. Автоход также проверен 24 ноября 2026 года в гостевой партии против бота Marko на Chess.com: расширение выполнило несколько ходов за белых и продолжило игру после ответов бота. Авторизованные партии и все варианты настроек сайта не проверялись.

## Правила Chess.com

Используйте расширение для тренировок и экспериментов с компьютерными ботами. [Правила Chess.com](https://www.chess.com/legal/fair-play) запрещают помощь движка в партиях против людей, включая нерейтинговые; для игр с компьютерными ботами предусмотрено исключение.

## Код и сборка

| Файл | Назначение |
| --- | --- |
| `manifest.json` | Настройки расширения |
| `content-source.js` | Отслеживание доски и подсказки |
| `panel.js` | Интерфейс |
| `auto-move.js` | Клики по клеткам и выбор фигуры при превращении |
| `move-delay.js` | Случайная пауза и отмена отложенного хода |
| `tracker.js` | Восстановление позиции по легальным ходам |
| `background.js` | Запуск и отмена анализа в Worker |
| `content.js` | Готовый браузерный bundle |
| `engine/` | Stockfish JS/WASM |
| `vendor/` | chess.js |
| `sources/` | Архив исходников Stockfish |

После изменения исходников пересоберите `content.js` из корня проекта с установленным Node.js:

```sh
npx --yes esbuild@0.25.12 content-source.js --bundle --outfile=content.js
```

Затем нажмите **«Перезагрузить» / Reload** у дополнения в `about:debugging` и обновите вкладку Chess.com.

Проверка пакета:

```sh
npx --yes web-ext@8.9.0 lint --source-dir .
```

Тесты планировщика пауз (Node.js 22+):

```sh
npm test
```

В версии 0.5.1 проверка не нашла ошибок. Остаётся предупреждение `Unexpected Callee` в неизменённом минифицированном файле Stockfish.
