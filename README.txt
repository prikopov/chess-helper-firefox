Chess Experiment — Firefox, версия 0.2.0

Установка для эксперимента
1. Распакуйте chess-helper-firefox.zip в отдельную папку.
2. В Firefox откройте about:debugging#/runtime/this-firefox
3. Нажмите «Загрузить временное дополнение» (Load Temporary Add-on).
4. Выберите manifest.json из распакованной папки.
5. Обновите открытую страницу chess.com. Справа внизу появится панель.
6. Начните новую партию и включите анализ ДО первого хода.
   Для проверки можно открыть https://www.chess.com/play/computer

Это временная установка: после перезапуска Firefox повторите шаги 2–4.
Для постоянной установки в обычный Firefox нужна подпись Mozilla.
Файл ZIP нельзя установить как подписанное расширение из магазина.

Использование
— ▶ включает анализ, Ⅱ выключает. Подсказки доступны для обеих сторон.
— Жёлтая рамка: откуда ходить. Зелёная: куда ходить.
— Оценка указана с точки зрения белых. Положительная — в пользу белых.
  Очередь хода, нотация и глубина доступны при наведении на ход и оценку.
— Время анализа: 0,6 / 1,2 / 3 секунды, плюс загрузка движка.
— ⋯ открывает время анализа и FEN.
— При выключении анализа подсказка исчезает.
— Расширение не делает ходы и не взаимодействует с часами.

Если подключаетесь посреди партии
Откройте ⋯, вставьте полный FEN текущей позиции
и нажмите ↵ или Enter. Фигуры должны совпадать с доской.
FEN обязан правильно задавать очередь хода, рокировки, поле взятия
на проходе и счётчики. По одному расположению фигур этого не узнать.
При несовпадении или пропуске ходов подсказки убираются.
Кнопка ⧉ копирует последнюю отслеженную позицию, а не
восстанавливает неизвестную позицию с сайта.

Ограничения прототипа
Поддерживаются обычные шахматы и стандартные DOM-доски Chess.com
с классами piece / square-XY. Варианты, Chess960, некоторые экраны
и будущие изменения разметки сайта не поддерживаются.
Если между наблюдениями прошло больше двух полуходов, либо переход
неоднозначен, понадобится FEN или новая партия. Анимация может
задержать подсказку. Пропущенные позиции расширение не угадывает.
Stockfish Lite слабее полной сборки Stockfish. Победа не гарантируется.

Правила площадки
Chess.com запрещает движки во время партий против людей, включая
нерейтинговые. Исключение предусмотрено для игры против компьютерных
ботов. Проверяйте прототип на ботах и в анализе.
https://www.chess.com/legal/fair-play

Данные и разрешения
Нет внешнего API и запросов к серверу анализа. Движок JS/WASM упакован
внутри. Расширение читает DOM только на chess.com, ничего не сохраняет
и не отправляет позиции. Доступ к аккаунту и cookies не запрашивается.

Проверки
Пройдены автоматические проверки логики: рокировки обеих сторон,
взятие на проходе, превращение пешки, два полухода между наблюдениями,
потеря синхронизации, новая партия, чтение классов фигур.
Пройден интеграционный тест в настоящем Firefox без окна на локальной
тестовой доске: загрузка WASM через фон расширения, получение хода,
обновление позиции, очистка устаревшего совета, ввод FEN, выключение.
Авторизованная партия на действующем Chess.com не проверялась.
web-ext lint: 0 ошибок; 1 предупреждение анализатора на минифицированном
немодифицированном файле upstream Stockfish (Unexpected Callee).

Исходники и сборка
content-source.js + panel.js + tracker.js + vendor/chess.js — исходники панели.
content.js — готовый браузерный bundle, его загружает manifest.json.
Для пересборки из папки расширения, при установленном Node.js:
npx --yes esbuild@0.25.12 content-source.js --bundle --outfile=content.js
background.js запускает движок в Worker, отдельно для каждой вкладки.
Движок перезапускается на новой позиции, чтобы не смешивать ответы.
